# SFTP 流程

MSSH 预留 SFTP 连接能力，用于浏览远程服务器目录。该功能当前隐藏，入口不对用户显示。

## 连接流程

1. 用户在保存连接中选择协议 `SFTP`。
2. 端口默认使用 22，用户可以自定义端口。
3. 连接时使用保存密码；如果没有保存密码，则弹窗输入密码。
4. JSch 创建 SSH 会话，并打开 `sftp` 通道。
5. 连接成功后读取当前远程目录。
6. UI 显示目录和文件列表。

## 首版功能

- 显示当前远程目录。
- 显示目录和文件列表。
- 点击目录进入。
- 返回上级目录。
- 刷新当前目录。

## 安全说明

SFTP 与 SSH 共用保存连接和密码加密逻辑。MSSH 不依赖系统 `sftp` 命令。

SFTP 虽然当前隐藏，也必须使用 App 私有 `known_hosts` 文件校验主机密钥。首次连接未知主机会按当前 SSH 策略自动接受并写入，后续连接继续校验。
