# UI 流程

MSSH 只做手机竖屏界面。

默认方向是竖屏。主界面提供横版/竖版切换按钮，方便平板横屏使用；该按钮只在主界面显示。

## 页面

## 主机列表

首屏展示已保存的 SSH 主机，并提供新增、编辑、删除和连接操作。

主机列表顶部还提供本地 CMD 入口，用于打开 Android 本机命令终端。

## 主机编辑

主机编辑页填写展示名称、协议、主机名、端口、用户名、认证类型和可选保存密码。

新增连接时默认协议是 `SSH`，端口保留自定义输入；默认端口为 22。

SFTP 功能当前隐藏。协议选择控件使用浅色文字，避免在深色背景中看不清。

密码输入框默认不可见，右侧提供眼睛斜线小图标按钮。点击后密码变为可见，按钮变为无斜线眼睛小图标；再次点击恢复不可见。该按钮必须使用图标，不使用文字。

保存密码使用独立复选框。只有用户勾选时，保存主机才写入加密密码；未勾选时只保存连接信息，连接前再弹窗输入密码。

每个表单项必须使用独立标题加输入控件的结构，例如“名称”标题在输入框上方，不能只依赖输入框 hint 表达字段含义。

新增/编辑连接弹窗不能使用系统默认白底配浅色文字。表单区域使用灰色或深色背景，字段标题使用更深的黄色或高对比颜色，确保在弹窗里清楚可读。

## 终端页面

终端页面针对手机竖屏使用优化：

- 顶部栏显示连接标题，右侧提供 `log` 按钮。
- 中间是终端输出区域。
- 底部是命令输入区域或终端输入桥接。
- 快捷键栏提供常用终端按键。

SSH 终端和本地 CMD 终端复用相同的竖屏终端布局。本地 CMD 终端的命令在 Android 手机本机执行。

SFTP 远程文件列表页面代码暂时保留，但当前不对用户显示。

SSH 终端和本地 CMD 终端发送命令后，命令输入框必须继续保持焦点，并保持软键盘可继续输入。终端输出滚动到底部时不能抢走命令输入框焦点。

终端输出区域需要使用有状态的 VT 屏幕解析，处理 ANSI 控制序列、颜色码、括号粘贴模式控制码、清屏、光标移动、擦除行和替代屏幕，避免把 `ESC` 序列直接显示成乱码。

`ll`、`vi`、`vim`、`nano` 等命令依赖终端屏幕状态。MSSH 需要优先保证这些命令的基础交互可用，体验尽量接近电脑终端。

SSH 终端输入分两种模式：普通 Shell 模式下，用户输入的内容必须停留在底部输入框，点击 `send` 或软键盘发送后才提交到远端；进入 `vi`、`vim`、`nano` 等替代屏幕程序后，输入框才作为原始键盘输入桥接。本地 CMD 终端始终保留整行命令发送模式。

SSH 终端的快捷键栏和物理键盘 Tab/左右方向键在两种模式下都必须可用。普通 Shell 模式下，如果输入框中已有未发送文本，点击 Tab 或左右方向键时先把输入框内容同步到远端，再发送对应按键。

SSH 终端 PTY 尺寸根据终端输出区域和当前字体动态计算。键盘弹出、屏幕旋转、横版按钮切换或布局变化后，需要重新计算列数和行数并同步到远端。

终端尺寸计算必须扣除输出 TextView 的左右和上下内边距，使用等宽字体实际测量列宽和行高，避免远端以 80x32 默认尺寸输出导致 `ll`、`vi`、`vim`、`nano` 布局错位。

## 设置页面

设置项包括字体大小、快捷键栏显示状态和主题偏好。

## 屏幕方向

`MainActivity` 默认请求竖屏。用户可以在主界面点击横版按钮切换到横屏，或点击竖版按钮切回竖屏。布局仍使用响应式约束，以适配不同尺寸设备。
